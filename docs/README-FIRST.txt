ORBIT CLASSROOM 1.0  –  README FIRST / NAJPREJ PREBERI
=======================================================

ENGLISH
-------
1. Teacher computer: double-click OrbitMaster.exe (no installation).
   If Windows says "Windows protected your PC": click "More info" -> "Run anyway".
2. In Orbit Master click "Download setup package" (Orbit-Agent-Setup.zip).
3. Student computers: unzip the package, double-click Install-Orbit-Agent.cmd,
   confirm the administrator prompt. (Mass install: OrbitAgent.exe --install --silent)
4. Orbit Master -> "Find computers" -> "Search network" -> "Add selected".

Full guide: GUIDE_EN.txt  (also inside the program: Help & guide)
Network: TCP 21400 and UDP 21401 to the student computers, same network.

SLOVENŠČINA
-----------
1. Učiteljev računalnik: dvokliknite OrbitMaster.exe (namestitev ni potrebna).
   Če Windows prikaže »Windows je zaščitil vaš računalnik«: kliknite
   »Več informacij« -> »Vseeno zaženi«.
2. V programu Orbit Master kliknite »Prenesi namestitveni paket« (Orbit-Agent-Setup.zip).
3. Učenčevi računalniki: razširite paket, dvokliknite Install-Orbit-Agent.cmd in
   potrdite skrbniško okno. (Množična namestitev: OrbitAgent.exe --install --silent)
4. Orbit Master -> »Poišči računalnike« -> »Preišči omrežje« -> »Dodaj izbrane«.

Celotna navodila: NAVODILA_SL.txt  (tudi v programu: Pomoč in navodila)
Omrežje: TCP 21400 in UDP 21401 do učenčevih računalnikov, isto omrežje.
